# Summary of Security Group & NACL

- **Security Group**
  - Stateful - The return traffic is automatically allowed.
  - 10/4 rules - (Deny all inbound by default + Allow all outbound).
  - Rules allow - (Inbound & Outbound).
  - Evaluated all rules before deciding to allow or deny traffic.
- **NACL**
  - Stateless - Return traffic is allowed manually.
  - VPC

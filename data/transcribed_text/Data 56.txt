SGD with momentum:

On start $t$:
Compute $dw, db$ on current mini-batch
$$v_{dw} = \beta v_{dw} + (1-\beta) dw$$
$$v_{db} = \beta v_{db} + (1-\beta) db$$
$$w = w - \alpha v_{dw} \quad;\quad b = b - \alpha v_{db}$$
$\beta = 0.9$ has good value (composed of other values)

RMSprop can also speed up $gd$:

On start $t$:
Compute $dw, db$ on mini-batch

$$S_{dw} = \beta S_{dw} + (1-\beta) {dw}^2 \quad \text{— small}$$
$$S_{db} = \beta S_{db} + (1-\beta) {db}^2 \quad \text{— larger}$$
$$w = w - \alpha \frac{dw}{\sqrt{S_{dw} + \varepsilon}} \quad;\quad b = b - \alpha \frac{db}{\sqrt{S_{db} + \varepsilon}}$$

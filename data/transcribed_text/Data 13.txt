# LR with Multiple Features:
## Multiple features : (Multiple Inputs)

$x_1, x_2, x_3, x_4 \longrightarrow x, w \longrightarrow y$

$f(w) = \sum_{i=1}^{n} w_i x_i + b \leftarrow$ Without Vectorization

Vectors $\begin{cases} \vec{w} = [w_1, w_2 ... w_n] \\ \vec{x} = [x_1] \end{cases}$

$\therefore f(\vec{w}) = \vec{w} \cdot \vec{x} + b \longleftarrow$ With vectorization

It is called "Multiple LR"

Vectorization:
- More faster & efficient (Computer does parallely)
$f = np.dot(w, x) + b$

# SGD for Multiple LR:

Repeat {
$w_j = w_j - \alpha \frac{\partial}{\partial w_j} J(\vec{w}, b)$
$b = b - \alpha \frac{\partial}{\partial b} J(\vec{w}, b)$
}

Repeat {
$w_1 = w_1 - \alpha \frac{1}{m} \sum_{i=1}^{m} (f(\vec{w}, b)(\vec{x})^i) - y^i) x_1^i$
$\vdots$
$w_n = w_n - \left(\frac{1}{m} \sum_{i=1}^{m} (f(\vec{w}, b) (\vec{x})^i) - y^i\right) x_n^i$
}

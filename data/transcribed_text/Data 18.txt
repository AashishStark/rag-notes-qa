- Numpy:
  - package is manipulated
  - used for:
    - manipulate data for w-dimesion ($n >= 2$)
    - without for-loops.
    - array used $\leftarrow$ `ndarray`
    - `numpy.array` = `numpy.array` (only 10 decimals)

* properties *
  - `ndarray.ndim` $\leftarrow$ no. of dim
  - `ndarray.shape` $\leftarrow$ $(w, h)$ rows, columns
  - `ndim` $\leftarrow$ $w \times w$ (No. of elements)
  - `dtype` $\leftarrow$ types (int32, int64)
  - `itemsize` $\leftarrow$ floating + 8 (64/8)
  - size * dtype $\leftarrow$ size in bytes of each element
  - `data` $\leftarrow$ Buffer containing actual data
